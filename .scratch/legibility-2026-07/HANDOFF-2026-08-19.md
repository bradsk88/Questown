## Input injection does NOT work — don't retry it

`wtype` delivers keys to the container's own apps (proved: typed text into the IntelliJ
terminal) but keys never register in the GLFW client window (Tab/Return do nothing on menus,
F2 writes no screenshot). `ydotool` is dead too: no `/dev/uinput`, no sudo. Hence: **menus
are unreachable; use `-Pautojoin`, and drive in-game state via server-side harness code
(hold mode's aim tracker), not by acting as a player.** Mouse: same story.

## New process gotchas (written in blood — real hours lost today)

- **`pkill -f`/`pgrep -f` self-matches your own bash argv.** Three times today a compound
  command killed its own shell mid-pipeline because the pattern text was in the command line.
  ALWAYS bracket one char: `pgrep -f '[G]radlew runServer'`, `pkill -f '[B]ootstrapLauncher'`.
  The latter also matches the *server* JVM — prefer `[G]radlew run(Client|Server)`.
- **Gradle must run on JDK 17**: `JAVA_HOME=$HOME/.gradle/jdks/jdk-17.0.20+8`. System Java is 21
  and Gradle 7.2's Groovy fails to recompile `build.gradle` on it ("Unsupported class file
  major version 65") — it only *appeared* to work when the build-script cache was warm. If you
  edit build.gradle with JAVA_HOME wrong, all Gradle invocations fail until you fix the env.
- **Held servers hold `run/world/session.lock`.** Kill the held server (`pkill -f
  '[G]radlew runServer'` + the JDK child matching `-Dquestown.autotest`) before launching the
  next `runServer`, or the new one dies with `DirectoryLock`.
- **Never join a client while a scenario is mid-run** — it perturbed the farmer warp pass into
  an infinite "Loaded villager state from NBT: []" loop once. Launch server → wait for
  HOLDING → then launch client.
- When a commit cycle is done, `git push` is still Brad's job — but note pre-commit doesn't
  trigger under pi (the `.githooks` allowlist checks CLAUDECODE/AGENT/CURSOR_AGENT; pi sets
  none of these). Consider adding `AGENT=1` or a pi var to the hook's allowlist — the
  COMPLEX.md work was done anyway this session (see `commands/test/COMPLEX.md`).
- Massive working-tree noise: `git status` shows ~700 mode-only/noise changes
  (old mode 100644 -> new mode 100755) predating this session, plus untracked `references/`.
  Left untouched on purpose; worth a housekeeping pass sometime.
