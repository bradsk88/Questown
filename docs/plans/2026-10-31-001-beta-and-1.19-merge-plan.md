## 3. Decision for the dev: how the code reaches 1.19

The 1.19 branch has an older `mc/Compat` (397 lines vs 799 here), a 10-line `RenderContext`, and
no `loader/` package. Everything outside the seam calls the *current* seam API.

- **A. Seam first (recommended).** PR 0 gives 1.19.2 the current seam API: `loader/` with a
  Forge 1.19.2 implementation in place of `loader/neo/`, the missing `Compat`/`Util` methods,
  `RenderContext` over `PoseStack`, the network codecs on Forge's channel. No behaviour change;
  verified by the 1.19 build and its autotests. Every later PR then copies version-free files
  unchanged (81% of main files carried no version marker at the 2026-07 probe; the gate's
  residual list has 27 entries, which get 1.19 variants in the PR that needs them. Note: the
  strangler closed at 23 on 2026-10-13, so the list has grown by 4 since, which the gate is meant
  to prevent; worth a look before PR 0).
  Cost: PR 0 is large (est. 4-6k lines, mostly mechanical) and is the only hard port.
- **B. Feature backports.** Each feature PR is rewritten against the old 1.19 API.
  Cost: every PR is a port, reviews compare two different shapes, and the two branches keep
  diverging (each future feature needs porting again).

A makes the 1.19 branch "this tree + a 1.19 seam", which is what the strangler work was for.
