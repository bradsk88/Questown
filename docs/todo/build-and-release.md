Minecraft version 1.20.6 unlocks the ability to set a tick rate, which is extremely useful for making held run tests more time-efficient.

However, the modding community typically only released 1.20.1 and 1.21.1 versions, with nothing in-between.

Let's set up something that enables us to use 1.20.6 for development, but makes sure we always back-port to 1.20.1 for releases.
